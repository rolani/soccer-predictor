# Correct score — 1 or 2 singles

Correct score is historically weak (MASTER ~25%). Output **1 or 2 singles**, never a 3-fold acca.

The web **Gameweek** tab is a different product: every remaining Big-5 matchday fixture gets a score for Twitter. This command stays 1–2 gated betting singles.

Follow `.cursor/skills/soccer-predictions/SKILL.md` (research workflow). Do not use the hybrid or short-acca product rules.

**Day:** assume today unless specified. EST remaining-kickoff rules apply.

Only pick a score when **multiple** signals agree: repeated H2H scoreline, form GF/GA, defensive stats, and a model (Forebet/dratings) on the same score. If fewer than 1 match qualifies, output none.

If 2 picks: kickoffs within 1 hour of each other (EST). Stake as **separate singles**. Show each price; do not sell a combined 100–500x ticket.

Save to `.predictions/YYYY-MM-DD/HH-MM-SS_correct-score-<today|tomorrow>.md` with columns # | League | Match | Tip | Odds | Kickoff (ET).
